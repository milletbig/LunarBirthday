## 📖 项目简介

在现代数字生活中，主流的日历软件（如 Google Calendar、Outlook、iOS 日历等）通常很难完美支持**每年重复的农历生日提醒**。

本项目是一个基于 Python 和 CustomTkinter 开发的桌面端小工具。它可以将你亲友的农历生日，一键批量推算并转换为未来数十年（默认 30 年）的公历日期，最终生成一个标准的 `.ics` 日历文件。你只需将该文件导入手机或电脑的日历应用，即可实现完美的农历生日周期性提醒！

---

## ✨ 核心功能

- **🔄 双向自动换算**：只需输入公历或农历其一，按下回车即可自动补全另一项。
- **📅 传统农历显示**：自动解析并显示传统干支纪年与中文农历日期（如：`1992壬申年九月廿八`）。
- **🧭 农历 / 公历双轨**：每条记录可单独选择按农历或公历推算，公历 2 月 29 日在平年自动按 2 月 28 日处理。
- **📊 CSV 批量导入导出**：用表格批量维护名单，支持 UTF-8 与 GBK 编码，导入时自动跳过格式错误的行。
- **🏷️ 分类标签**：为每位亲友打上分类（如「家人」「同事」），导出时写入日历分类，方便在日历中筛选。
- **⚙️ 高度可定制**：
  - 支持为每个人独立设置**推算年数**（默认 30 年）。
  - 支持设置**提前提醒天数**（默认提前 7 天通知）。
  - 标题可选择不显示年龄、显示周岁或显示虚岁。
- **🖱️ 现代化交互**：基于 CustomTkinter 的深色模式 UI，支持**鼠标拖拽**对条目进行自由排序。
- **💾 配置本地存储**：支持将录入的亲友名单保存为本地 `.json` 文件，下次打开一键读取，告别重复输入。
- **🌐 跨平台兼容**：生成的 `.ics` (iCalendar) 文件支持导入苹果生态、Google 日历、Outlook 以及小米、华为等主流安卓日历。

## 🗓️ 提醒与历法说明

每条记录都可以单独选择**农历**或**公历**，生成的提醒严格跟随该行的历法选项，不会一律按农历处理：

- 选择「农历」：把农历月日换算为目标年份的公历日期，事件与提醒都建在该日期。
- 选择「公历」：直接使用公历月日（2 月 29 日在平年退到 2 月 28 日），事件与提醒都建在该日期。

提醒（VALARM）始终相对事件最终日期提前 N 天，并在当天 H 点触发；当天二次提醒为可选项。若某行选择农历但同时填写了公历，生成时以农历为准，公历仅作参照，界面会提示两者不一致。

## ⚠️ 已知限制

- **年份范围**：农历推算可靠区间为 1900–2100 年，超出后停止推算并提示。
- **闰月**：仅当目标年份确实存在该闰月时才生成事件，否则跳过该年并计入统计。
- **月小补偿**：农历当月没有三十时自动按廿九处理，并在事件描述中标注。
- **公历 2 月 29 日**：平年按 2 月 28 日处理，并在事件描述中标注。
- **提醒精度**：ICS 使用全天事件（`VALUE=DATE`），「提前 N 天的具体小时」在不同日历客户端上的呈现可能不一致。
- **提醒规则**：仅支持「提前 N 天 + 当天 H 点 + 可选当天二次提醒」，不支持多条自定义规则。
- **CSV 导入**：仅做字段类型转换，推算年数 / 提醒天数越界会在界面标红，不在导入阶段拦截；编码支持 UTF-8 与 GBK。
- **分类**：分类为自由文本，暂不提供分类管理与筛选界面，日历端的筛选能力取决于客户端。
- **虚岁**：按「事件农历年 − 出生农历年 + 1」计算，不覆盖地方性增岁习俗。
- **UID 与重复导入**：事件 UID 由「条目 ID + 目标年份」决定；删除后重建条目会生成新 UID，日历中的旧事件需手动清理。
- **本地存储**：配置默认保存在 `%APPDATA%/LunarBirthday`，仅限本机，无云同步；自动备份保留最近 5 份。
- **分发**：Windows 可执行文件未签名，可能触发 SmartScreen 提示；暂不支持自动更新。
